Synthé3-ng — French voice Michel

Version 0.4.0 targets the NVDA 2026.2 API and x64 Windows processes.

Open the .nvda-addon package, install it and restart NVDA. Select Synthé3-ng — Michel (français) in NVDA speech settings.

Rate 50 and pitch 50 match the Linux defaults. Volume 100 is unity gain; inflection 0 keeps the historical intonation. The voice speaks French only.

Automated tests use the real engine with simulated audio, plus DLL checks under Wine. Successfully tested with NVDA 26.3 (2026.3) on Windows 11 26H2 during long work sessions without problems, with very good responsiveness. Acoustic latency has not been measured. Switch back to your previous synthesizer if necessary.

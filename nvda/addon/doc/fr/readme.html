Synthé3-ng — Michel pour NVDA

Version 0.4.0. Voix française Michel, moteur natif C, sans serveur externe ni fichier audio temporaire. Cible : NVDA 2026.2, processus Windows x64.

Installation

  1. Ouvrir le fichier synthe3-ng-0.4.0.nvda-addon sur Windows et accepter son installation dans NVDA.
  2. Redémarrer NVDA lorsque proposé.
  3. Ouvrir le menu NVDA, Préférences, Paramètres, Parole, puis le choix du synthétiseur. Sélectionner Synthé3-ng — Michel (français).

La voix Michel parle français. Cette extension ne fournit pas de voix pour les autres langues.

Réglages

  • Débit : 50 correspond au niveau moteur 4 ; 77 au niveau 13. Les seize niveaux historiques sont conservés.
  • Hauteur : 50 correspond au niveau moteur 5, le réglage du port Linux.
  • Volume : 100 correspond au gain normal ; 0 coupe le son.
  • Inflexion : 0 conserve l’intonation historique. Une valeur positive active la modulation de phrase ; 20 correspond à une intensité de 1,5 demi-ton, 40 à 3 et 100 à 7,5. Cette option ajoute une passe de calcul.

La ponctuation et les prononciations de symboles suivent les réglages NVDA. L’épellation, les changements de hauteur des majuscules, les pauses de parole et les indices de lecture sont pris en charge.

Premier essai

Lire quelques lignes, saisir du texte, naviguer rapidement avec les flèches, interrompre la parole avec Contrôle, puis lancer une lecture continue et essayer la pause et la reprise habituelles de NVDA. Vérifier que les anciens mots ne reviennent pas après une interruption.

Cette première version a été vérifiée automatiquement avec le moteur réel, une sortie audio simulée et la DLL sous Wine. Un essai utilisateur sous NVDA sur Windows a confirmé le bon fonctionnement et une très bonne réactivité. La latence acoustique n’a pas été mesurée. Les champs de compatibilité du manifeste ciblent l’API NVDA 2026.2.

En cas de problème

Revenir au synthétiseur précédent dans les paramètres Parole. Pour retirer l’extension, utiliser le gestionnaire d’extensions de NVDA et redémarrer lorsque demandé. En cas d’erreur, conserver le journal NVDA (menu Outils, Visionneuse du journal), la version NVDA, la version Windows et le périphérique audio utilisé.
